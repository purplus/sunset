彩霞指数怎么来的

晚霞的本质是"云被夕阳照亮"：天太晴、云太少，没东西可染；云太厚，光透不过来。理想的火烧云通常出现在中高层有 30%–60% 云量、空气通透、湿度不高、风力适中的傍晚。本工具用天文算法计算日落时刻，再取该时段前后一小时的实时气象预报（Windy 或 Open-Meteo），按下方权重综合给出 0–100 的彩霞指数。

云量 · 权重 55%
峰值落在 30–60%，太晴或全阴都减分
湿度 · 权重 15%
越低越通透，偏高易发闷、发灰
能见度 · 权重 15%
越高越清亮，霾多会吃掉颜色
风力 · 权重 15%
轻风最宜，大风会把云吹散
数据来源：Windy 气象（需 API Key，可选）／ Open-Meteo 气象预报（免费开放接口，可切换 GFS / ECMWF 模型）＋ NOAA 天文算法。Windy 数据源需在 windy.com 免费申请 Point Forecast API Key；未配置 Key 时自动回退 Open-Meteo。指数为启发式模型，仅供出片规划参考，天气变化快，建议在日落前 1–2 小时再确认一次。
